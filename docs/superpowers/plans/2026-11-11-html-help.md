# Offline HTML Help

## Requested result

F1 in the Settings window opens bundled local HTML Help in the default
browser. A visible Help (F1) button provides the same action. Help is English,
like the application, self-contained, accessible and usable offline.

## Implementation

- Add Help/index.html covering current dictation, Review, models, keyboard,
  appearance, history, recovery and local data behavior.
- Publish Help/index.html as Help.html next to the executable, and include
  Help.html in the existing flat MSI payload list. No installer is built.
- Handle unmodified F1 before child controls, suppress held-key repeats, and
  show a useful Settings message if the file or default HTML handler is missing.
- Do not save settings or change recording state when opening Help.

## Verification

- Validate HTML structure, internal links, no remote assets or dependencies.
- Build/publish and verify packaged Help matches the source.
- Run existing Core tests and verify F1 from a focused Settings control opens
  the installed Help. Check browser rendering when available.
- Deploy and relaunch the idle client with the normal shortcut enabled.
