# Recording and Review concept

Open recording-review.html in a browser to explore the proposed interface.

The page is self-contained and uses sample text and device names. It does
not capture a microphone, contact the ASR API, modify the system clipboard,
or type into another application.

Use the state buttons to inspect recording, finalization, target changes,
and an unavailable API. The gear button opens the settings concept,
including Verify after recording and the Verification model dropdown.

The current dropdown contains one example verifier. The intended client
obtains available choices from the shared API registry.

DOM-simulated checks cover the concept's interaction logic. Automatic
browser rendering inspection was not completed, and the page does not prove
native Windows focus behavior or dictation performance.
